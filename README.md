# Reliable Policy Iteration:  Performance Robustness Across Architecture and Environment Perturbations

This is the official codebase for the "Reliable Policy Iteration: Consistent Performance across Function Approximators" paper published at the [Indian Control Conference 2025](https://controlsociety.org/icc/).

We use SB3's implementations of DQN, PPO. We adapt SB3's DQN implementation to create Double DQN and RPI_DQN. Also, we use the [implementations of DDPG and TD3](https://github.com/sfujim/TD3/tree/master) as provided by the authors of TD3. We adapt DDPG to create RPI_DDPG.
